# holbertonschool-web_back_end

Back-end web development projects for Holberton School.

## Projects

| Directory | Description |
| --- | --- |
| `python_variable_annotations` | Type annotations in Python 3: function signatures, variable types, complex types from `typing`, and duck typing. |
| `python_async_function` | Asynchronous programming with `asyncio`: coroutines, running them concurrently, tasks, and measuring runtime. |
| `python_async_comprehension` | Asynchronous generators, async comprehensions, and running comprehensions in parallel with `asyncio.gather`. |
| `pagination` | Simple, hypermedia and deletion-resilient pagination over a CSV dataset. |
| `NoSQL` | MongoDB from the shell and from Python with PyMongo. |
